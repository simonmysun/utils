Bcrypt Basic Auth Generator

Generate two useful values:

  • Basic Authorization header: Base64 of username:password.
  • htpasswd line (bcrypt): username:$2b$... for nginx/Apache Basic Auth files.
Input
Higher = slower but stronger. 10–12 is typical.
Outputs
Masked display; copy reveals full value.
Use as HTTP header: Authorization: Basic <base64>
Save into a password file for nginx/Apache, one per line.
Useful for Makefiles or templating where $ needs escaping.
Notes
  • All hashing happens locally in your browser via bcryptjs.
  • The Basic header uses UTF‑8 for username:password before Base64.
  • Servers typically accept bcrypt variants $2b$ or $2y$.
