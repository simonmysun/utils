# 截图合并工具

一个功能强大的单页面应用，用于合并多张截图为一张连续的长图。特别适合合并从长文档或网页中截取的多张截图。

## 功能特性

### 🖼️ 图片管理
- 支持多种图片格式 (PNG, JPG, WEBP, etc.)
- 批量上传和管理
- ↑↓ 按钮调整图片顺序
- 实时预览

### ✂️ 图片编辑
- **精确裁剪**: 像素级别的边缘裁剪控制
- **图片变换**: 90度旋转、水平/垂直翻转
- **接缝调整**: 相邻图片重叠区域的精细调整
- **实时预览**: 所有编辑操作的即时视觉反馈

### 🤖 智能合并
- **重复内容检测**: 自动识别网页头部、底部导航栏等重复内容
- **智能裁剪建议**: 基于图像相似度算法的自动优化建议
- **接缝优化**: 自动寻找最佳的图片拼接位置

### 📱 响应式设计
- 桌面端完整功能体验
- 移动端触摸友好界面
- 自适应布局

### 💾 导出功能
- PNG格式高质量输出
- 一键下载合并后的图片
- 自定义文件名

## 技术架构

### 前端技术栈
- **纯原生实现**: 不依赖第三方库
- **模块化设计**: 清晰的代码结构
- **Canvas API**: 高性能图像处理
- **现代CSS**: Flexbox, Grid, CSS变量

### 核心模块
1. **ImageLoader**: 抽象的图片加载器，支持文件和URL加载
2. **ImageProcessor**: 图片编辑和合并引擎
3. **SmartMerger**: 智能分析和自动优化算法
4. **UIController**: 用户界面交互控制器

2. 使用本地服务器运行（推荐）:

## 使用指南

### 基本操作流程
1. **上传图片**: 点击上传区域选择多张截图
2. **调整顺序**: 使用图片列表中的 ↑↓ 按钮调整排列顺序
3. **选择方向**: 选择垂直或水平拼接方式
4. **编辑图片**: 
   - 点击图片进行选择
   - 使用裁剪工具调整边缘
   - 旋转或翻转图片
   - 使用智能合并功能自动优化
5. **预览效果**: 查看最终合并效果
6. **下载图片**: 保存合并后的长图

### 智能合并功能
1. 启用"智能识别"选项
2. 点击"应用智能建议"
3. 确认系统识别的重复内容
4. 自动应用优化建议

## 常见问题

### Q: 支持的最大图片尺寸是多少？
A: 单张图片最大支持50MB，实际处理能力取决于设备性能。

### Q: 为什么某些操作很慢？
A: 大尺寸图片的处理需要较多计算资源，建议先压缩图片或使用性能更好的设备。

### Q: 智能合并不准确怎么办？
A: 可以手动调整裁剪参数，或者调整相似度阈值（开发者选项）。

### Q: 移动端功能限制？
A: 移动端支持所有核心功能，但界面布局针对触摸操作进行了优化。
