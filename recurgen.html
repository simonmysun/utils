循环事件生成器 → ICS

选择起始时间、循环方式与截止条件，生成一系列事件并导出 .ics。支持农历 / 艾宾浩斯 / 自定义 JS，标题描述支持模板变量。

1. 起始时间

2. 循环方式 常规

每个数字是距起始日的天数。第一个通常为 0（当天）。
必须 return 一个 Date 数组。会受下方"截止条件"再次裁剪。

3. 截止条件

安全上限：最多生成 1000 个事件。

4. 事件内容

点击变量插入到最后聚焦的模板输入框。导出的每个事件描述末尾会附加一行编码后的原始输入。

5. 恢复 / 编码

编码串也会出现在每个事件描述末尾（RECURGEN:...），可复制回来重新生成。

模板变量说明

{{i}} 序号(从1)　{{i0}} 序号(从0)　{{total}} 总数
{{week}} 距起始周序号(从1)　{{offsetDays}} 距起始天数
{{date}} 公历日期　{{time}} 时间　{{datetime}} 日期时间
{{year}}/{{month}}/{{day}}/{{weekday}}
{{lunar}} 农历全称　{{lunarDate}} 农历月日　{{ganzhi}} 干支年　{{zodiac}} 生肖
{{tz}} 时区　{{tzOffset}} UTC偏移　{{utc}} UTC时间
表达式：{{= 表达式 }} 可写任意 JS，能用上面所有变量。
例：第 {{= Math.ceil(i/7) }} 周　{{= i*2 }}　{{= week }}
